# Frozen whole-boundary discovery checks

These seven fixtures were generated by an independent collaborating agent for
the v0.5 task and their hashes were frozen before the first discovery run. They
are targeted acceptance cases, not a blind historical benchmark or a claim of
general circuit optimization. They were available during implementation, so
they are not held-out generalization evidence. The emitters are in
`tests/test_v05_structural_discovery_acceptance.py`; `fixtures.json` preserves
the original untagged bytes, clean-wire contracts, and hashes.

Each run receives only native circuit bytes, declared clean inputs, and the
`Q*toffoli` objective. No cut, producer annotation, hypothesis, replacement,
custom constructor, or learned archive is supplied. The suite varies nonlinear
producers, linear and nonlinear consumers, intermediate encodings, input bases,
physical wire layouts, and evaluation schedules. One ten-input case deliberately
exceeds the default joint-synthesis truth-table budget. Every emitted best
circuit is independently checked using native execution over every public input,
including arbitrary accumulator values, all physical outputs, and exact sign.

Both comparisons use one round, beam four, at most twelve proposals, at most
200 operations, 32 symbolic variables, 65,536 ANF terms, and 65,536 product
terms. Constructors keep their version's default internal limits; the new joint
constructor allows at most three ANDs, eight truth-table inputs, one second,
10,000 states, and 100,000 expansions. Equal public caps do **not** mean equal
CPU time or an equal number of implemented constructors.

The integrated interim results, before the final generic schedule/measurement
extension, are retained in `current-interim.json` and `baseline-portable.json`:

| Build | Deep bank retirements | No gain or bounded | Native checks passed | Discovery wall time |
| --- | ---: | ---: | ---: | ---: |
| Installed v0.4.2 | 1 / 7 | 6 / 7 | 7 / 7 | 0.276 s |
| Integrated worktree interim | 6 / 7 | 1 / 7 | 7 / 7 | 5.880 s |

Wall time sums the discovery calls and excludes interpreter startup and the
independent native acceptance checks. The calls ran on the same host but not
under an isolated CPU benchmark protocol. JSON records preserve each result,
failure reason, exact resource bill, measured duration, and source-code hashes.
The runner verified that the package-source hashes did not change during each
run. This binds that interim run, not a later release. Final-current receipts
must be rerun after the implementation is frozen.

The interim objective changes are `80→14`, `80→28`, `80→14`, `80→14`, `99→5`,
and `45→35`; the ten-input chain remains at `323` and remains in the denominator.
v0.4.2 improves only the encoded-parity case, from `99` to `7`. The original
`current-preflight.json` preserves the earlier three-of-seven result before
generic ANF factoring and representation search were integrated. Physical
retirement and full-boundary checks are recorded independently of constructor
annotations.

The separate nonheldout scale examples have interim changes `2944→45` for
12 inputs and `1344→81` for 24 inputs; v0.4.2 finds no deep improvement in either.
These objective reductions describe the emitted examples. They are not measured
host-level speedups or evidence that a full decoder has been optimized.

The tests additionally reject a phase-mutated replacement and a clean-output
leak, and refuse the same physical retirement when the clean promise is removed.

## Portable replay

From the repository root, use the same Python interpreter and kickmix version
for both packages. The runner requires an installed package directory containing
`strata`, and each output directory must be new or empty:

```sh
python benchmarks/v05-structural/run.py --package-root src --label current --suite frozen --out /tmp/strata-current-frozen
python benchmarks/v05-structural/run.py --package-root /path/to/installed-v042 --label v0.4.2 --suite frozen --out /tmp/strata-v042-frozen
```

The current package uses its native `deep_only=True` search mode. v0.4.2 has no
equivalent mode: the runner leaves its constructor catalog unchanged, then
selects only verified candidates that improve the objective and retire at least
two physical scratch wires. This capability difference is recorded explicitly.
No new constructor, marked region, or replacement is supplied to either build.

`run-manifest.json` binds every Python source file in the selected package, the
runner, fixture bytes, public search ceilings, and runtime versions. The runner
checks package and fixture hashes again before publishing `summary.json` and
refuses to publish if either changed during execution. Full native construction
receipts and fresh per-fixture archives remain in the output directory. Reported
times distinguish discovery calls, the engine's search interval, native checks,
and total wall time. Final-run summaries also record Linux process high-water
RSS, including imports, discovery, and native checks; this is not a per-constructor
peak or a circuit memory metric. Equal ceilings do not imply equal CPU time.

Use `--suite scale` to run the separate 12- and 24-input examples in
`scale-fixtures.json`. Those examples were used during constructor development
and are explicitly **nonheldout**. Their ceilings are 512 operations and 128
symbolic variables, with the other public limits unchanged. The 12-input example
has a complete native check including both dirty accumulators; the 24-input
example uses a deterministic native smoke sample. Its full input and outcome
coverage, when verified, comes from the symbolic boundary proof alone. Native
measurement draws are never counted as all-outcome proof.

The [joint-encoding example](architecture-interaction.kmx) is a separate
development fixture with four public controls, four arbitrary accumulator
bits and three clean helpers. Reproduce the native search with:

```sh
strata search benchmarks/v05-structural/architecture-interaction.kmx \
  --out work/interaction --clean-inputs 8,9,10 --cost 'Q*toffoli' \
  --rounds 1 --trial-seconds 10
```

Its [receipt](architecture-interaction-result.json) separates mathematical
formulations, native verifications and cheaper structural results. The
independent [three-case comparison](../v05-holdout/yield_fresh/README.md)
measures transfer to additional sources. A [scaled decoder trial](decoder-gf4-transfer.json)
records a zero-gain result on a generator-produced GF(4) component.
