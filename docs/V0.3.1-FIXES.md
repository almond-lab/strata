# v0.3.1: reported failures and measured lookup construction

This patch addresses thirteen reports filed against v0.3.0 (#36–47 and #51). These are
software and scoped construction fixes; no competition improvement is claimed.

| Issue | Fix and regression scope |
| --- | --- |
| [#36](https://github.com/almond-lab/strata/issues/36) | Proved-zero resets are identities for Boolean floors. Kernel evidence receives its valid clean assumptions, including canonical wire remapping; a reset never creates a zero promise. |
| [#37](https://github.com/almond-lab/strata/issues/37) | Gradient agreement is independent of probe eligibility. Both eligibility flags and scorer receipts remain visible. |
| [#38](https://github.com/almond-lab/strata/issues/38) | Exact quadratic receipts include safe float summaries; large rational formatting does not change interpreter-wide limits. Continuous coordinates accept None/zero step placeholders, or steps may list only quantized coordinates. |
| [#39](https://github.com/almond-lab/strata/issues/39) | `evaluate-file --clean-inputs` binds the complete zero-input/restoration promise and checks dirty outputs and phase. Finite domains must honor the same promise. |
| [#40](https://github.com/almond-lab/strata/issues/40) | Separate paid-skeleton index permits varying linear layers and nonperiodic surroundings; layer hashes remain distinct. Explicit window caps take precedence over defaults. Skeletons remain observations, not equivalence proofs. |
| [#41](https://github.com/almond-lab/strata/issues/41) | Region lifting continues after budget cuts instead of making the remaining file opaque. Open scopes stay unknown until a safe boundary. |
| [#42](https://github.com/almond-lab/strata/issues/42) | Functional/slack search clocks start after window preparation, with separate timing and real CLI search budgets. |
| [#43](https://github.com/almond-lab/strata/issues/43) | Reapplied constructors reuse boundary metadata or generate unique names, including phase and learned-template paths. |
| [#44](https://github.com/almond-lab/strata/issues/44) | Native CCX bilinear decompositions are extracted and independently verified. Bounded seeded dependency/flip searches work beyond the complete catalog, retaining the best known construction and reporting catalog size. CCZ phase tensors and measurements remain outside that extractor. |
| [#45](https://github.com/almond-lab/strata/issues/45) | Confidence may use `log2_delta` or `delta`; count-resource names and empirical identity are documented. An optional declared schema rejects missing resources before running the verifier. |
| [#46](https://github.com/almond-lab/strata/issues/46) | Completed exhaustive rank exclusions strengthen the scoped lower bound even when later search times out or retains a larger construction. |
| [#47](https://github.com/almond-lab/strata/issues/47) | Source/canonical parent hash conventions are explicit and interoperable. Source-labelled mismatches fail by streaming preflight before native loading or alignment. |
| [#51](https://github.com/almond-lab/strata/issues/51) | Candidate proof recovery starts around changed spans and grows within a declared budget; it does not lift the entire unchanged circuit. Widening attempts and control-context obstructions are reported. Native parsing/alignment still have whole-file costs. |

The new [measurement-aware lookup constructor](MEASURED-LOOKUPS.md) addresses
the accompanying user report that permutation-only constructors cannot handle
HMR cleanup. It preserves measurement provenance, dirty output values and
phase repairs while factoring quadratic and cubic table arithmetic. It is not a
universal table compiler.

Focused evidence is in `test_file_query_regressions_v031.py`,
`test_streaming_budget_issues.py`, `test_tensor_seeded.py`,
`test_numeric_reported_issues.py`, `test_measured_lookup.py` and
`test_lookup_review.py`. See [kernel recovery](KERNEL-RECOVERY.md),
[tensor search](TENSOR-SEARCH.md), and the updated numeric/adapter guides for
API examples and limits.

The fresh inverse-square-root research run produced no verified gain. Its
specific capability gaps were filed separately as [#48](https://github.com/almond-lab/strata/issues/48)
(fractional-phase recovery), [#49](https://github.com/almond-lab/strata/issues/49)
(streamed promised-domain boundary reconstruction), and
[#50](https://github.com/almond-lab/strata/issues/50) (file-first host-objective
integration). Those research tickets and historical #9/#10/#19 acceptance
milestones remain open; this patch does not silently claim them completed.
