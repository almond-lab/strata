# v0.4 workflow benchmark

The reference benchmark runs existing scripts through the actual offline
bubblewrap boundary. It compares twenty separate sequential invocations with
one declared twenty-setting sweep using two workers, on the same local host.

| Measurement | Result |
| --- | ---: |
| Sequential twenty-setting run | 6.10 s |
| Declared sweep, two workers | 4.10 s |
| Outcomes | Identical: 18 accepted, 2 rejected |
| Resume | 0.96 s; all 18 accepted results reused |
| Rebuild report and agent packet | 0.13 s |
| Native circuit reference pipeline | 0.29 s; independently accepted |
| Non-contest word-count pipeline | 0.30 s; independently accepted |

This is approximately 1.49× lower elapsed time from bounded concurrency on these
small fixtures. It is not an algorithmic optimization, reduction in total compute,
or forecast of throughput on full quantum circuits. Workload, setup and verifier
overheads matter. Results were measured after validation subprocesses completed,
on a shared host without exclusive CPU reservation.

The controller made twenty explicit `run_experiment` calls in the sequential
case and two planning/execution calls in the sweep case. These are counted API
calls, **not measured human interventions**. Installation and human onboarding
were not timed. There is no claimed percentage reduction in a research team's
working hours.

The numeric fixture includes CSV curve reading, a retained checkpoint, a
separate residual verifier and a discontinuous declared cost formula. The circuit
fixture emits native `.kmx` and is checked against a fixed-width parity contract;
the third fixture uses JSONL and a non-contest token-count contract. All three
use manifests without handwritten task adapters. Their small reference verifiers
are not official competition scorers.

Run from the source checkout on Linux with usable namespaces:

```bash
.venv/bin/python scripts/benchmark_workflow.py \
  --out /tmp/strata-workflow-benchmark --count 20 --workers 2
```

Use a new output directory for an independent measurement. The script retains
attempts, verifiers, artifacts and reports, and rejects differing sequential/sweep
outcomes. The [machine-readable receipt](V0.4-WORKFLOW-BENCHMARK.json) records the
measured environment and evidence handles; the script reconstructs new evidence
on a later run.

Screening/continuation calibration is tested separately. Its saved-compute
numbers come from replaying held-out measured trajectories and are labelled
retrospective; they are not added to this benchmark's measured speedup.
