# Exact fractional observables

`strata search` and `strata restructure` can compare native constructions for an unconditional kickmix circuit containing `Z_POW`. On a basis input, let `F(x)` be the output bits and `p(x)` the phase exponent in `exp(i*pi*p(x))`. The pass reads each exponent from kickmix's canonical circuit text. It computes the Boolean predicate at each diagonal gate, sums the weighted predicates modulo two, emits that diagonal in the input basis, and follows it with the circuit for `F`. It checks the complete result independently.

For example, computing `q2 = q0 AND q1` into a declared zero wire, applying `Z_POW q2 0.25`, and reversing the compute uses two Toffolis and one rotation. Kickmix can express the same observable with exponents `0.125` on each input and `1.875` on their parity. This version uses two CNOTs, three rotations, and no helper. Each version preserves the two arbitrary input bits. Pricing rotations can change which version wins.

For predicates with a common coefficient, the pass forms the binary digits of their integer sum. Mutually exclusive flags can collapse to a single flag. Overlapping flags produce a carry that receives twice the original coefficient. A second formulation computes exact Walsh coefficients on each nonlinear predicate with at most ten supporting inputs, combines identical parities, and lowers the parity changes with restored CNOTs. Affine predicates can have wider support within the semantic budgets. Every emitted coefficient must round-trip through kickmix at exactly its intended value. A formulation requiring finer resolution is recorded as unlowerable.

The checker represents arbitrary touched inputs with reduced ordered Boolean decisions, fixes only declared-clean entries to zero, and checks every output plus each bit plane of the dyadic exponent modulo two. The phase includes its constant term. An optional zero-output contract checks that the named wires return to zero in both circuits. Receipts include the native phase precision, proof budget use, and an independent SDK check with exact shot phases. That replay enumerates up to seven arbitrary touched inputs, samples larger inputs, and records a skip if native state allocation would exceed its cap.

Native registers retain their physical bindings. Omitting a trailing helper requires a declared zero promise and a successful proof that its boundary value is preserved. Measurement, resets, classical writes, and classically controlled operations are outside this constructor's scope. Unsupported operations and exhausted budgets produce a scoped result.
