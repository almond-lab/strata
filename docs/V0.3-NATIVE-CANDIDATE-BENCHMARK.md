# One million actual native candidate replays

The measured run materialized, parsed and executed **1,000,000 distinct canonical kickmix programs** in **595.851 seconds**: **1,678 actual candidates per second** through the complete benchmark pipeline. Every program ran on all **256 assignments** of six input bits and two dirty output accumulators, with two explicitly zero helpers. The total is **256,000,000 native input trajectories**, separately counted from candidates.

The retained receipt is [V0.3-NATIVE-CANDIDATE-BENCHMARK.json](V0.3-NATIVE-CANDIDATE-BENCHMARK.json). The earlier 10,000-program pilot remains in [V0.3-NATIVE-CANDIDATE-BENCHMARK-PILOT.json](V0.3-NATIVE-CANDIDATE-BENCHMARK-PILOT.json). This is an actual million-program run, not an extrapolation from that pilot or a count of input shots.

The family is an unordered set of four distinct rank-one products in a 3 × 3 × 2 GF(2) tensor. There are 147 atoms and 18,671,940 possible specifications. Fixed-seed sampling rejects repeated specifications; 27,754 repeated draws were discarded before execution. Different specifications may implement the same function, which is why distinct Boolean maps are reported separately.

Each specimen is lowered into a real reversible X/CX/CCX program, parsed by kickmix and statically measured. All specimens execute in `kickmix.Simulator`; a Python prefilter rejects none. The native results are compared with an independently evaluated tensor specification and with a fixed reference function. All ten physical outputs, the restored helpers and sign phase are checked. **Eight programs implement the reference; the other programs are not claimed as valid replacements for it.** Matching a specimen's own specification establishes correct lowering, not an optimisation win.

## Where the measured time went

| Stage | Seconds |
| --- | ---: |
| Unique specification generation | 14.567 |
| Coefficients and verified reversible emission | 358.260 |
| Native parsing and static resource measurement | 31.542 |
| Native simulator creation and input setup | 69.743 |
| Native `sim.do` execution | 2.402 |
| Native output and phase readback | 23.604 |
| Independent oracle and reference comparison | 69.852 |
| Canonical artifact hashing | 22.789 |
| Complete wall time, including remaining bookkeeping | **595.851** |

The native execution kernel's isolated rate is about 416,246 candidates per second. The measured **end-to-end** rate is 1,678 per second. Emission, setup, readback and checking remain part of a real candidate pipeline; the kernel rate must not be substituted for total throughput.

Programs have four Toffolis and approximately 27 native instructions on average, with ten physical wires. This is a bounded episode benchmark, not a run of one million full contest circuits, an official host verifier, or a proof of discovery quality. It does not include durable storage of every individual candidate file. The seed, family definition, program-sequence hash, representative native artifacts, environment and script hash are retained for replay.

The [guided-versus-random experiment](V0.3-CANDIDATE-BENCHMARK.md) separately measures algebraic proposal efficiency and checks its finalists natively. Its two million screened specifications must not be added to this benchmark's million native programs as if they were the same kind of work.

## Reproduce

```sh
.venv/bin/python scripts/benchmark_artifact_pipeline.py \
  --candidates 1000000 \
  --progress-every 50000 \
  --out docs/V0.3-NATIVE-CANDIDATE-BENCHMARK.json
.venv/bin/pytest tests/test_native_candidate_benchmark_v03.py -q
```

Progress reports count executed native programs and input trajectories independently. Regression tests also inject a phase error and a dirty helper after emission; native replay rejects both.
