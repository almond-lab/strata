# v0.4.1: experiment reliability and complete supported boundaries

This patch addresses the eight new reports #52–59. Software fixes and exact
supported fixtures are separate from achieving a new competition optimization.

| Issue | Change |
| --- | --- |
| [#52](https://github.com/almond-lab/strata/issues/52) | Bilinear recognition partitions quadratic terms and preserves affine terms for tensor construction. Non-bipartite or higher-degree functions remain ineligible. |
| [#53](https://github.com/almond-lab/strata/issues/53) | Private reflinks where supported, streaming copies otherwise, and default compact retention of attempt copies whose identical bytes remain verified in the object store. No writable hard links into immutable artifacts. |
| [#54](https://github.com/almond-lab/strata/issues/54) | Empty text and JSONL outputs are valid by default; a boolean `nonempty` override makes content mandatory. Missing files, invalid JSON/CSV and missing selected metrics still fail. |
| [#55](https://github.com/almond-lab/strata/issues/55) | Bounded canonical Boolean decision diagrams avoid dense ANF expansion for supported classical controls, zero tests and measured uncomputation. Budget failures retain instruction context. |
| [#56](https://github.com/almond-lab/strata/issues/56) | Staging preserves basenames/extensions, co-locates declared source siblings, and preserves filenames on verifier artifact and checkpoint arguments. |
| [#57](https://github.com/almond-lab/strata/issues/57) | Comparison identities bind the verifier and objective rather than unrelated worker implementations, allowing compatible baseline and candidate manifests to compare. |
| [#58](https://github.com/almond-lab/strata/issues/58) | Whole supported XOR-table lifting first proves target independence, workspace restoration and zero phase over formal outcomes, then extracts the finite address table and checks native replay. Unsupported or undeclared restricted-domain functions remain explicit. |
| [#59](https://github.com/almond-lab/strata/issues/59) | Declared finite draw sets and aggregate policies replace minimum-over-draw ranking. Partial, conflicting, rejected or unmatched observations cannot become the verified winner. |

See [comparison contracts](V0.4.1-COMPARISONS.md),
[semantic scope](V0.4.1-SEMANTICS.md), and
[staging/retention](V0.4-WORKFLOW.md). Retention reduces persistent duplicate
storage; on filesystems without reflinks, temporary copies still contribute to
peak disk usage. Resume restores artifacts and checkpoints from their hashes.

The earlier research gaps #9, #10, #19 and #48–50 remain separately tracked.
Neither symbolic table recovery nor a new verified-cost comparison establishes
a profitable rewrite, global circuit understanding or a population expectation
from a finite sample of verifier draws.

The concurrent chemistry research run also exposed a rejected-verifier receipt
without success-only resource fields. Such a rejection now stays
`rejected_by_verifier`, with its original reason and no verified cost, rather than
being relabelled as artifact validation failure during cost extraction.

Existing records remain readable. Execution still enforces the original frozen
reader/runtime identity: finish or resume a v0.4.0 experiment in its pinned
environment, or create an explicit descendant using v0.4.1. Upgrading the library
does not silently rewrite an old experiment's verification or draw contract.

Validation: **736 passed, six default namespace skips**, with all six covered
in the separate real-sandbox checks. The installed wheel was checked outside the
checkout and its 54 Python modules matched the tested source bytes. See
[the recorded scope](V0.4.1-VALIDATION.json).
