# A connected-agent trial on a supplied chemistry loader

A fresh AI agent received only the Strata skill and the generated evidence
brief for the pinned chemistry loader. It was not given a desired replacement
or a task-specific adapter. It read the inferred functions, native views,
measured costs and the previous automatic search's negative result.

The [loop receipt](CONNECTED-LOOP-RECEIPT.json) confirms that the next brief
contains the agent's reported blockers and the larger recovery targets.

The trial produced three hypotheses, but no justified candidate or optimization:

| Mechanism | Evidence used | Next necessary capability |
|---|---|---|
| Cross-region nonlinear basis factoring | A large contiguous span contains 161 paid operations; later controls use earlier nonlinear values | A representation that preserves factored expressions instead of expanding every Boolean monomial |
| Preparation/consumer/phase-cleanup fusion | 80 reset, HMR and conditioned-CZ operations divide the graph | Explicit reset semantics, measurement-outcome ownership and complete phase-debt contracts |
| Helper lifetime scheduling and recomputation | A large auxiliary register and delayed cleanup | Proven clean-wire ownership and equivalence under internal wire remapping |

These are hypotheses reported by the connected agent, not proven savings.
The input artifact and derived static measurements are recorded in
[FILE-REAL-SMOKE.json](FILE-REAL-SMOKE.json). Detailed private source excerpts
and the agent's report remain in the local run store.

## Feedback that changed the workflow

The original brief's top six targets each contained one Toffoli. The agent
correctly challenged that granularity: exact local algebra was leading the
search toward small changes while the larger coupled function remained unknown.
The brief now reports this fragmentation and supplies broader measured spans
as **semantic-recovery targets**. Those spans carry no invented contract or
rewrite authorization; their cleanup and conditional dependencies still need
recovery.

The agent reported that a two-Toffoli span required 89 boundary wires and a
65,536-term allowance to recover a degree-three map. A 161-Toffoli span still
hit the product-work budget. This diagnoses a representation and proof-backend
limit. Increasing the number of attempts on the same small-window construction
would not address that limit.

Pre-build observations and hypotheses are retained as
`reported_by_connected_agent`. They feed the next brief without acquiring a
proof or candidate certificate. Candidate runs separately report exact
counterexamples, measured deltas and accepted gains only after verification.

## Scope

The file objective used native static counts, not the competition's chemistry
cost model. A reduction in this loader's own width does not establish a
reduction in the host's peak width or portfolio cost. Those placement and
verifier facts were not supplied to file mode.

No candidate was fabricated to make the trial look successful. No official
verifier was run and no competition submission was made. The trial's intended
four-minute limit was exceeded by about 22 seconds, including report writing;
no further experiment was launched afterward.
