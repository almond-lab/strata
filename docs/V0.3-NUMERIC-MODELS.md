# Numeric trend and quadratic models

`strata.numeric_models` adds three separate tools: uncertainty-aware convergence forecasts, observed stopping rules, and bounded quadratic quantization studies. None establishes a numerical error guarantee for an unmodelled computation. Reports use `evidence_kind="fitted_trend"` or `"model"`; detailed `model_kind` labels do not turn them into measured host evidence.

## Convergence forecasts

```python
from strata.numeric_models import forecast_convergence

report = forecast_convergence(
    measured_runs,
    checkpoint="frozen-checkpoint-hash",
    objective="residual_norm",
    unit="absolute_error",
    target=1e-8,
    horizon=200,
    bootstrap_samples=1000,
    seed=7,
)
```

Each run must have a distinct `run_id`, `independent=True`, matching `checkpoint`, `objective`, and `unit`, and at least five points of the form `{"step": 10, "value": 0.002}`. Steps must increase strictly; values must be finite. The checkpoint and metadata identify the frozen experimental setup. Step coordinates must have the same meaning and units in every supplied run. Declaring independence does not prove it: repeated measurements of one optimization curve are not independent runs.

The forecaster fits constant, finite linear, exponential-asymptote, and power-asymptote trends. Temporal held-out points rank each run's fits. A seeded bootstrap samples whole runs and alternative trend families, preserving run-level heterogeneity. It returns separate `mean_trend_band` and `new_run_prediction_band` objects; bands contain their nominal level, steps, lower/median/upper curves. Their uncertainty is conditional on the fitted families and the supplied run population.

A single curve or fewer than three declared independent runs returns `insufficient_evidence`, with no probability. Three or four runs may produce explicitly model-based bands, but no probability. By default, a target probability requires at least five independent runs and three distinct trajectories. It estimates the chance that a new same-population run reaches the target **at the requested horizon**, under this fitted model. It does not estimate first-passage probability, certify ultimate convergence, or guarantee that one existing run will succeed. `direction="max"` handles maximizing objectives.

Eight or more runs with aligned measured endpoints additionally produce an independent-run holdout diagnostic. The test runs are excluded from the models used for that diagnostic. Its observed coverage and mean error concern the observed endpoint budget; they do not calibrate future extrapolation. `calibrated_certificate` remains false. A finite linear trend has no claimed asymptotic floor, so its asymptotic entry is `None`.

The report binds the input data through `source_hash` and the complete forecast configuration through `model_hash`. A forecast is not evidence that a calculation actually ran. Store the report as an artifact, then wrap a chosen scalar as a `fitted_trend` evidence value when using the numeric-study ledger.

## Observed stopping rules

Stopping uses a separate API and retained observed artifacts. Forecast values are rejected.

```python
from strata.model import canonical
from strata.store import Store
from strata.numeric_models import declare_stop_rules, evaluate_stop_rules

identity = dict(checkpoint="frozen-checkpoint-hash",
                objective="residual_norm", unit="absolute_error")
store = Store("run/.strata")
declaration = declare_stop_rules(
    [{"kind": "threshold", "operator": "<=", "value": 1e-8, "patience": 2},
     {"kind": "budget", "step": 1000}],
    **identity, declared_before_step=0,
)

# This payload comes from an actual recorded measurement job.
payload = dict(**identity, step=1, value=0.002)
observation = dict(payload, kind="measured",
                   artifact_hash=store.blob(canonical(payload).encode()))
decision = evaluate_stop_rules([observation], declaration, store=store)
```

Threshold rules require the last `patience` observations to satisfy the chosen comparison. Budget rules compare the latest observed step to the declared cap. Stagnation rules use `window`, `minimum_improvement`, and optional `direction`: they trigger when the best observed improvement within that window does not exceed the declared amount. Multiple rules combine by OR.

The evaluator verifies the declaration hash, requires its declared step to precede the supplied observations, and reads every observation blob from the Store. Checkpoint, objective, unit, step, and value must match those retained bytes. This binds the decision to the reported measurements; it does not independently establish how those measurements were produced. The caller must retain the declaration before running the experiment—an asserted earlier step is not a trusted wall-clock timestamp. No forecast can change a rule or override a checkpoint contract. The function returns a decision and does not kill jobs, mutate checkpoints, or spend resources.

## Curvature and compensated quantization

The model convention is

`E(x) = offset + (x - target)^T H (x - target)`.

There is no implicit factor of one half. `H` must be symmetric and positive semidefinite. Continuous coordinates may compensate without bounds; every remaining coordinate has its own finite quantization grid.

```python
from strata.numeric_models import quadratic_analysis, exact_grid_floor

sensitivity = quadratic_analysis(
    [[2, 1], [1, 2]], target=[0.5, 0],
    continuous=[1], steps=[0.1, 1],
    parameter_names=["quantized_parameter", "compensator"],
)

floor = exact_grid_floor(
    [[2, 1], [1, 2]], target=["1/2", 0],
    grids={0: [0, 1]}, continuous=[1],
)
assert floor["minimum"] == "3/8"
assert floor["minimizer"] == ["0", "1/4"]
```

`quadratic_analysis` reports the Schur-complement matrix after continuous compensation, raw and compensated diagonal sensitivity scores `H_ii * step_i**2`, cross-coupling, and spectral diagnostics. It also reports each coordinate's remaining curvature if all other coordinates can compensate. Scores rank local model sensitivity; they are not independent per-parameter error budgets, and correlated terms cannot generally be summed as independent errors. The floating-point PSD test and pseudoinverse are numerical diagnostics, never an exact certificate.

`exact_grid_floor` interprets integers, rational strings, and decimal spellings as exact fractions. It verifies rational PSD structure, handles singular continuous blocks with an exact stationary solve, and enumerates every combination in the supplied grids. A successful result includes the exact rational minimum and a minimizing point. Its `certified=True` flag has the explicit `certificate_scope="supplied finite rational model only"`. It is not an actual nonlinear-pipeline error floor, unrestricted lattice optimum, or host acceptance proof. Continuous compensation is unrestricted; bounded compensators require a different model or inclusion in finite grids.

If dimension, grid-state, or rational-coefficient budgets prevent exact enumeration, the result is `bounded`, with `certified=False`. The fallback reports a clearly labelled numerical lower-bound estimate from the compensated spectral curvature and separately compensated coordinate estimates. This can be weak, including zero. It must not be promoted to an exact floor. Increasing a search budget or observing a low value does not certify a stronger lower bound.
