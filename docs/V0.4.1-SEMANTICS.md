# Exact factored boundaries and complete XOR tables

The v0.4.1 fixes for issues #52, #55 and #58 preserve the boundary promise and
measurement provenance while avoiding unnecessary dense polynomial expansion.

Bilinear accumulator recognition partitions only the quadratic terms. Constants
and linear terms remain in the tensor's affine remainder, including controls
that occur only linearly. Odd-cycle quadratics and higher-degree terms still
fail this recognition. The existing circuit decomposition remains the tensor
search seed.

`strata.semantic.analyze_complete` first attempts bounded ANF and then uses a
canonical reduced ordered decision graph if polynomial expansion exceeds its
term or product budget. Its successful alternative status is **exact_factored**,
not the ANF schema's `exact`. Outputs, classical values, measured values,
activation conditions and the final sign have graph roots. Restored workspace
and discharged HMR phase debts are exact Boolean facts for every boundary
input and every formal outcome. A factored receipt is not an arbitrary quantum
instrument equivalence theorem, nor a measurement-resource lower bound.

`inspect-file` retains these additional receipts in
`semantic-lift.json.factored_regions`; ordinary ANF coverage keeps its original
denominator. `floors` returns the exact receipt with an explicit unsupported
floor result. `restructure` retains `boundary_receipts` and passes the typed
receipt to constructors. The boundary comparator independently retries canonical
decisions and requires identical ordered measurement provenance. A changed
phase correction is rejected even when the classical table is unchanged.

`strata.factored_semantic.lift_lookup_table` proves a complete XOR oracle by:

1. Recovering the support of every output delta and proving independence from
   every dirty target and formal measurement outcome.
2. Proving zero final phase for all outcomes, preservation of the address, and
   restoration of every declared clean wire.
3. Enumerating the inferred narrow address and replaying all addresses with
   native kickmix. This replay uses zero initial targets and native outcomes;
   the preceding symbolic proof establishes arbitrary target and outcome scope.
4. Converting the complete table to ANF with the Boolean Möbius transform.

The receipt records the address/target mapping, table, ANF deltas, explicit
clean promise, native replay and exact proof. `restructure` exposes it as
`lookup_tables` and as `context['lookup_table']` to every constructor. The
measured lookup constructor preserves measurements and correction order while
using this complete boundary. This release does not promise a cheaper table
implementation or authorize dropping measurement provenance. A circuit whose
outputs depend on dirty targets, whose workspace leaks, or whose phase is
nonzero is rejected. Reachable parity promises are never inferred; use the
separate explicit finite-domain checker for those domains.

All work remains bounded. The complete backend's preliminary ANF attempt uses
at most 65,536 terms/products; the decision fallback uses `max_terms` as its
node limit and **32 × `max_product_terms`** as its uncached decision-operation
limit. This conversion accounts for cheaper Boolean decision operations and is
also used by inspection and equivalence. Direct `analyze_factored` and
`lift_lookup_table` calls expose `max_nodes` and `max_apply_steps` explicitly.
At most 512 symbolic variables are supported by this backend. Lookup extraction
defaults to 12 address bits and 1,048,576 address/output cells. Every exhaustion
records its operation and limit; ANF product failures also report the exact
instruction, operand term counts and attempted product count. Increasing a
budget never changes the boundary assumptions.

Validation includes arbitrary dirty states, classical writes and nested scope
snapshots, every forced HMR branch on small tables, deterministic random
programs checked against independent native kickmix, phase/output/workspace
mutations, and garbage collection while comparing two complete circuits.
The synthetic wide table test has 11 address and 40 dirty target wires.

For the historical `dfthcsos/angle_k_0.kmb`, the complete table was also checked
locally (the artifact is not distributed with this repository). This result is
specific to k=0; no claim is made for other loaders or their reachable domains.
The receipt contains 2,048 address rows, 40 targets and 24,192 ANF terms, with
all 77 explicitly zero workspace wires restored and all outcome phase debts
discharged. Native replay passes all 2,048 addresses. The generic decision
backend retained 16,318 nodes and used 30,642 node slots with collection; the
full traversal used 4,855,939 uncached decision operations.

```python
from strata.frontends import load_circuit
from strata.factored_semantic import lift_lookup_table

result = lift_lookup_table(
    load_circuit('angle_k_0.kmb'), clean_inputs=range(51, 128),
    max_operations=60000, max_variables=512,
    max_nodes=2000000, max_apply_steps=8388608,
)
assert result['status'] == 'exact'
assert result['native_replay']['status'] == 'passed'
```

Tests: `tests/test_semantic_v041.py`, `tests/test_factored_v041.py` and the
existing semantic, measured lookup, tensor and restructure suites.

The historical artifact's SHA-256 is
`06a64018000361fdf1e9cb672131a8766ef8b5f3d366ba0e2ae8ad13a8c41944`.
An end-to-end `restructure_file` run with `rounds=1`, `max_operations=60000`,
`max_variables=512`, `max_terms=2000000`, `max_product_terms=262144`, and
`clean_inputs=range(51,128)` completed locally in 64.07 seconds. Its full
42,153-instruction, 283-Toffoli boundary was `exact_factored`; its lookup table
was `exact`. The measured lookup constructor received the complete table and
returned a priced `no_gain` result. No resource saving or host verification is
claimed. Runtime is an observation from this machine, not a performance bound.

Native enumeration also has an independent `max_native_cells` budget (524,288
by default): `(physical qubits + physical classical bits) × address rows`.
Sparse high wire IDs therefore cannot cause an unbounded simulator allocation
behind a small touched-wire count. This check runs before creating the native
simulator and returns `native_replay_cell_budget` with the requested size.
